# 0004 Tailwind CSS with our own components

**Date:** 2026-11-03 · **Status:** accepted

**Decision.** Style with Tailwind CSS and a small set of our own components, with the school's colour set at runtime. Visual direction: clean and professional.

**Why.** Full control of the look and of per-school colours, no heavy UI library, and the styling approach carries to React Native (NativeWind) so mobile can share the same tokens.

**Gave up.** The speed of a ready-made kit such as MUI. We build the components we need, with tests, and list them in `docs/ui/design-system.md`.
